# wiki/ (source for the GitHub wiki)

These Markdown files are drafts of the team's GitHub wiki pages. The brief asks
the team to use the GitHub **wiki** to document design, development and testing,
so the marked copy must live in the wiki itself.

How to publish them:
1. On GitHub open the repo's **Wiki** tab and create the first page (this creates the wiki repo).
2. Clone it: `git clone https://github.com/<owner>/<repo>.wiki.git`
3. Copy these files in (the file name becomes the page title, hyphens become spaces) and push.

Keeping drafts here means wiki changes can be reviewed in pull requests too.
`_Sidebar.md` gives every wiki page a navigation menu.
